# Contributing

1. Open or link an issue before making substantial changes.
2. Keep engine code UI- and platform-independent.
3. Add tests for behavior changes and bug fixes.
4. Use small, focused pull requests.
5. Run `pnpm test`, `pnpm typecheck`, and `pnpm build` before opening a PR.
6. Avoid introducing dependencies without explaining the need in the PR.

Commit prefixes: `feat:`, `fix:`, `refactor:`, `test:`, `docs:`, `chore:`.
